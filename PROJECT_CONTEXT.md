# Project Aurora Context

## Project Name

Project Aurora

## Current Version

v2.1.4

## Project Goal

Project Aurora is a Windows local AI assistant control center. The long-term goal is to build a personal AI Companion with local AI inference, persona, memory, knowledge, mobile access, remote access, Live2D, and voice interaction.

It is not a simple chat application. It is intended to become a long-running personal AI system.

## Development Rules

Do not:

- Redesign the architecture without confirmation.
- Delete existing modules.
- Create duplicate systems.
- Create a second Memory system.
- Create a second Conversation system.
- Perform large refactors without confirmation.

Required workflow:

- Make small, scoped changes.
- Analyze first, then modify.
- Preserve existing module boundaries.
- Keep backward compatibility with existing data and interfaces.
- After each phase, report modified files and reasons before continuing.
